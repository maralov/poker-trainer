# Poker Trainer

Тренажер префлопу для 9-max кешу: чотири сценарії (відкриття, ізоляція лімперів,
проти рейзу, проти 3-бету), drill по накопичених помилках, ворота до постфлоп-етапу.

Веб-версія standalone-файла `poker-trainer.html` — з логіном через Google,
збереженням прогресу на сервері і синхронізацією між пристроями.

## Стек

| Шар | Технологія |
|---|---|
| Frontend | React 19 + Vite + TypeScript (strict) |
| State | zustand |
| Backend | Supabase: Postgres 17 + Auth + RLS (свого сервера немає) |
| Auth | Google OAuth |
| Тести | vitest — юніт (engine, черга синку) та інтеграційні (RLS, синк) |

## Швидкий старт

Потрібні Docker і Node 22+.

```bash
git clone https://github.com/maralov/poker-trainer.git && cd poker-trainer
npm install

# 1. Локальний Supabase (перший запуск тягне образи, це довго)
npm run db:start

# 2. Змінні оточення
/bin/cp .env.example web/.env      # локальні ключі вже вписані

# 3. Веб
npm --prefix web install
npm --prefix web run dev           # http://localhost:5173
```

Тренуватись можна без входу — прогрес лежить локально, відповіді чекають у черзі.
Вхід через Google вмикає синхронізацію між пристроями.

**Локальний вхід через Google** вимагає реальних OAuth-ключів у `supabase/config.toml`.
Без них локально працює все, крім самої кнопки входу; логіку синку покривають
інтеграційні тести.

## Тести

```bash
npm test          # engine, черга синку, компоненти — без Docker
npm run test:db   # RLS і наскрізний синк — потрібен запущений npm run db:start
```

Тести engine звіряються з еталоном, знятим із `poker-trainer.html`: склад усіх
діапазонів і 471 спот, згенерований референсною `preBuildSpot` під детермінованим
`Math.random`. Порт перевіряється проти оригіналу, а не проти чисел, вписаних
з голови — деталі в `web/src/engine/__fixtures__/README.md`.

Тести RLS перевіряють, що користувач не бачить чужих даних. Це не формальність:
anon-ключ публічний, і політики — єдине, що ізолює користувачів.

## Структура

```
poker-trainer/
├── PLAN.md               # початковий план (архітектура змінилась після Фази 1)
├── CLAUDE.md             # правила, архітектура, узгоджені відхилення
├── poker-trainer.html    # standalone-референс, джерело істини для ігрової логіки
├── supabase/
│   ├── migrations/       # схема, RLS, SQL-функції
│   └── tests/            # інтеграційні тести політик і синку
└── web/src/
    ├── engine/           # чиста ігрова логіка, без React і без мережі
    ├── api/              # клієнт Supabase, черга синку, серверний прогрес
    ├── store/            # zustand: прогрес, сесія тренування, auth
    ├── components/
    └── pages/            # Train / Ranges / Stats / Review
```
